# Exercice Collection


## 1) Encodage de nombre
Créer une application qui permet à l'utilisateur d'encoder des nombre réel.  
Une fois toutes les valeurs encodées, l'application calcul :  
- La moyenne  
- La somme  
- La valeur maximal  
- La valeur minimal  

Réaliser une solution avec :  
- Avec un tableau   
- Avec une collection générique → `List<...>`  


## 2) Liste de tache  
Créer une application de gestion de tache qui permet :  
- D'ajouter une nouvelle tache  
- De visualiser les taches  
- D'effacer toutes les taches  


## 3) Compter les voyelles d'un mot  
Créer une application qui permet à l'utilisateur d'encoder un texte.  
Ensuite, l'application compte chacune des voyelles du texte `(a, e, i, o, u, y)`.  


## 4) Application de scoring  
Réaliser une application qui permet d'encoder les scores pour du golf.  
- Dans un premier temps, l'application demande le nom _(Unique)_ de tout les joueurs.  
- Ensuite, l'utilisateur doit renseigner le nombre d'étape du parcours.  
- Pour terminer, l'application demande le score de chaque joueurs pour chaque étapes !  
  
Une fois toutes les données encodée, calculer et afficher :  
- The winner (Personne avec le score total le plus faibles).  
- Le joueur ayant fait le pire score lors d'une étape.  
- Afficher le classement des joueurs
