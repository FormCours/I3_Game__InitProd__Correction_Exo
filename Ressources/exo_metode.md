# Exercice Méthode

## Exercice 1
Réaliser le jeu du pendu en application console.

Regle : 
- Nombre de vie : 10.
- Mot entre 5 et 10 lettre.

Le code devra contenir (minimum) les méthodes suivantes : 
- GenererMotAleatoire() → Tips : Au debut, renvoyer une valeur connu 
- ObtenirLettre()
- VerifierLettre(...)
- AfficherMotATrouve(...) → Exemple : I _ _ E _ _ _ _ E
- AfficherGameover(...) → Message de fin de partie avec le resultat

_Les méthodes peuvent directement implémenté dans program.cs_
